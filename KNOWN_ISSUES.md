# Известные ограничения и оставшиеся проверки

Дата: 4 ноября 2026 года.

1. **Критическое ограничение доступности из РФ.** chatgpt.site возвращает 403 с трёх российских узлов, при этом Германия получает 200. Это регионально зависимый отказ защитного слоя хостинга, не сбой React/Supabase. Supabase из РФ отвечает штатным 401 без ключа. Подготовлено размещение на Amvera, но оно ещё не выполнено; исправление доступности пока не подтверждено.
2. **Границы мобильной проверки.** Локальные 375×812 E2E прошли; публичная форма регистрации проверена инструментом. Пользователь подтвердил полный сценарий в узком мобильном экране. Safari/Firefox и полный WCAG-аудит не выполнялись.
3. **Нет пагинации.** Поиск и статистика работают по загруженным строкам в пределах лимита Data API (обычно 1000). Для большего объёма нужны серверный поиск, пагинация и отдельные агрегаты.
4. **Одновременное редактирование.** Последняя запись заменяет поля; нет контроля версий и Realtime. Список обновляется при открытии/после сохранения и перезагрузке.
5. **Неоднозначный сетевой сбой.** Параллельная отправка одной формы заблокирована ref-замком и проверена в unit/E2E. Если сервер создал запись, но ответ потерялся, новая ручная попытка может создать дубликат: серверного idempotency key нет.
6. **Supabase MCP недоступен.** Каталог RLS не прочитан через MCP из-за Unknown tool. Пользователь сообщил о включённых политиках; защита двух пользователей фактически подтверждена настоящим Data API. Миграция повторно не запускалась. Полный аудит настроек Supabase не выполнялся.
7. **Внешний шрифт и размер сборки.** Google Fonts загружается извне, при недоступности используется системный шрифт. Есть предупреждения Rollup о комментариях стороннего Zod и JS-чанке более 500 kB; сборка успешно завершена.
8. **Тестовые записи оставлены.** Есть помеченные тестовые заявки, созданные при UI/API-проверках. Они принадлежат тестовым аккаунтам. Автоматического удаления и клиентского DELETE нет; удалять их без согласования не требуется.

Сайт и GitHub публичны по разрешению пользователя. Пользователь подтвердил оставшиеся production-сценарии, однако публичность не устраняет региональный отказ chatgpt.site из РФ. Новая ссылка Amvera должна быть проверена до сдачи.

Фактически ранее прошли TypeScript, линтер, сборка, 8 unit/component-тестов, 22 SQL-проверки, 6 E2E с подменой HTTP и настоящий API-прогон RLS. Пользователь подтвердил production CRUD, смену статуса и сохранность после обновления/повторного входа. Критическая функциональная ошибка не обнаружена; пределы проверки перечислены выше.

Amvera: runtime-параметры поддержаны и проверены локально; удалённый тариф, сборка, домен и доступность из разных стран пока не проверены. Существующие проекты бота/прокси не изменялись.
